# Hmarka — Dynamic Island для Windows

<img src="https://pixelredfox.github.io/hmarka-releases/icon.png" width="96" align="right" alt="">

Чорний «острів» угорі екрана Windows 10 і 11. У спокої це маленька пігулка з тим, що важливо зараз: музика,
таймер, нарада, дзвінок, завантаження. Наведіть мишку, і острів розкривається: плеєр, буфер обміну й полиця,
нагадування й нотатки, календар, погода, облік часу, ШІ-чат, коди 2FA, скріншоти й запис екрана.

## Встановлення

1. Завантажте **Hmarka-x64-Setup.exe** з [останнього релізу](https://github.com/PixelRedFox/hmarka-releases/releases/latest).
2. Запустіть його й оберіть папку. Права адміністратора не потрібні; .NET 8 інсталятор докачає сам, якщо його немає.
3. Острів з'явиться вгорі екрана. Налаштування — шестерня в розгорнутому острові або значок хмарки в треї.

Оновлення приходять самі: Hmarka перевіряє нові версії кожні 6 годин і встановлює їх після перезапуску.

## Раніше — Islet

До версії 0.3.0 програма називалася **Islet**. Якщо вона у вас стоїть, оновлення запропонує встановити Hmarka,
а нотатки, історія буфера, коди 2FA й налаштування переїдуть самі. Стару Islet після цього можна видалити.

ключем. Докладніше — [політика конфіденційності](https://pixelredfox.github.io/hmarka-releases/privacy.html).
